# FutsalTeamMaker (PoC)

フットサルのイベント・大会の主催者向けに、参加者の実力が均等になるようにチームを分ける iOS アプリの PoC です。

## できること

- 選手を名前と実力（1〜5）で選手名簿に登録する（端末内に保存。サーバーは使いません）
- 大会・イベントごとにフォルダを作り、名簿からメンバーを選ぶ
  - 新しい大会を作るときは、前回の大会のメンバーをそのまま引き継げる
  - ほかの大会のメンバーをまとめて追加することもできる
  - 名簿で実力を直すと、その選手が入っているすべての大会に反映される
- 大会のメンバーのうち今回参加する選手にチェックを入れ、チーム数（2〜8）を選んで分ける
- 分けるときの条件
  - 女性の人数がチーム間でそろうようにする（選手に性別を設定した場合）
  - 友達同士などを「同じチームにするメンバー」として選ぶ。大会ごとに設定し、「必ず同じチーム」か「できれば同じチーム」を選べる
  - 同じチームにできなかったメンバーは結果に表示する
- 各チームの人数・実力の合計・平均を表示する
- 分けた結果をドラッグ＆ドロップで手で直す。選手を長押ししてドラッグし、別のチームの選手の上で離すと入れ替わり、チームの選手がいないところ（チーム名など）で離すとそのチームへ移る
- 「分け直す」で、同じくらい均等な別の組み合わせを出す（手で直したあとは確認してから分け直す）
- 結果を LINE などに貼れるテキストで共有する（実力は載せません）
- 大会ごとに最新の結果を1つ自動で残す。分けたときと手で直したときに上書きし、大会の画面の「前回の結果」から開ける（分けた時点の選手の名前・実力・性別のまま残す）

## チーム分けの方法

`FutsalTeamMaker/Domain/TeamBalancer.swift`

結果の良さは次の順に比べます（前の条件ほど優先します）。

1. 「必ず同じチーム」のメンバーが分かれていない
2. 女性の人数の差が小さい
3. 実力の合計の差が小さい
4. 「できれば同じチーム」のメンバーが分かれていない

手順は次のとおりです。

1. 同じチームにするメンバーはひとかたまりとして、大きい順・実力の高い順（同じならランダム）に、空きのあるチームへ入れる
2. 2チーム間で1人ずつ入れ替え、結果が良くなるかぎり入れ替えを続ける
3. 1〜2 を40回試し、一番良かった結果の中からランダムに1つ選ぶ

人数はチーム間で最大1人までしか差が出ません。

## 開発環境

- Xcode 26 / iOS 17 以上 / SwiftUI + SwiftData
- プロジェクトは [XcodeGen](https://github.com/yonaskolb/XcodeGen) で生成します（`.xcodeproj` はリポジトリに入れていません）

```sh
xcodegen generate
open FutsalTeamMaker.xcodeproj
```

テスト（ロジックは Swift Testing、結果の画面のドラッグ＆ドロップは XCUITest。UI テストではデータをメモリ上にだけ保存します）:

```sh
xcodebuild test -project FutsalTeamMaker.xcodeproj -scheme FutsalTeamMaker -destination 'platform=iOS Simulator,name=iPhone 15 Pro'
```
